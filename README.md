# Excel Data Analysis & Interactive Dashboard

## Project Overview
This end-to-end data analytics project explores key performance metrics, operational trends, and business drivers using **Microsoft Excel**. By leveraging dynamic pivot tables, interactive slicers, and automated VBA macros, this workbook transforms raw data into an executive-ready dashboard to support data-driven decision-making.

## Tools & Technologies
* **Microsoft Excel:** Data cleaning, formula-driven modeling, conditional formatting, and structured tables.
* **Pivot Tables & Pivot Charts:** Multi-dimensional data aggregation and visual trend analysis.
* **Interactive Slicers:** Dynamic filtering across categories, time periods, and key segments.
* **VBA / Macros:** Automated data refreshes and interactive report navigation.

## Repository Structure
* `Excel_Analysis_Dashboard.xlsm` — Macro-enabled Excel workbook containing raw data, pivot tables, and the interactive dashboard.
* `Dashboard_Preview.png` — High-resolution screenshot of the final Excel dashboard for quick viewing.

## Key Business Insights
* **Performance Trends:** Tracked overall volume and revenue growth across key categories and timeframes.
* **Segment Breakdown:** Compared top-performing segments using dynamic pivot summaries and percentage-of-total metrics.
* **Interactive Filtering:** Enabled instant drill-downs into specific subsets of data via connected slicers.
* **Automated Reporting:** Streamlined repetitive formatting and table updates using embedded macros.

## How to Use This Project
1. **Clone or download** this repository to your local machine.
2. Open the `.xlsm` file in **Microsoft Excel** (click **Enable Content** if prompted to allow macros and slicers to function properly).
3. Navigate to the **Dashboard** tab and click the **Slicers** to filter charts dynamically.
4. Inspect the underlying **Pivot Tables** and **Data** sheets to review the formulas and aggregations.
